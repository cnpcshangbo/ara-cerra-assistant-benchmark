# Constraints and limitations

## Task and data boundaries
The implementation-aware convenience suite is small and reused. It is not a sample from user traffic; the control examples have been shown previously. Chinese prompts do not establish multilingual robustness. Truth means agreement with retained source products, not current state totals, independent extraction validity, exposure-adjusted risk or causal crash reduction. These limits bound C01–C07.

## Configurations and timing
Historical deployments, local paired inference and the API extension retain different paths, adapters and generation settings. Shared hardware reduces but does not eliminate confounding: model size and CPU offload differ. Request time includes loading, internal repairs and data operations; browser completion includes rendering. No monetary cost, energy, productivity gain or user tolerance study was measured. C03 and C06 are configuration-level claims.

## Scoring and unresolved attribution
Strict success is a conjunctive interface contract; redundant action fields can fail without a value change. MD17 applies a requested year prematurely under the frozen clarify-first policy. MD04's annual-row criterion is not explicit in its prompt. MD01 reaches a confirmed shared scope override, but absent raw planner records prevent reconstructing every model's interpretation. C02, C04 and C07 preserve these boundaries.

## Narrative review and audit amendments
Narrative review is single-reviewer AI assistance. Complete scoring guidance materially changed earlier judgments; original judgments remain archived. The original campaign's identity/browser enforcement layer was added after the written freeze. This is not an unamended externally preregistered trial. Original reviewer backend metadata is incomplete; the separate API reviewer context does not establish human expertise. C05 requires this disclosure.

## Public reproducibility and privacy
The public suite is a labeled derivative with a selected-record binding redacted. Original manifest hashes and public-file hashes are distinct. Public evaluated records allow aggregate recomputation but do not replace raw answers, browser evidence or private incident-source databases. Inspection code is scoped to the evaluated boundary, not a complete production deployment. Re-running fresh inference requires lawful source snapshots, model access and an application harness; exact replay of mutable provider aliases is not promised.

## Open work
Author names/order/affiliations and venue are unconfirmed. Independent domain review, a held-out suite, matched local/API comparison and human usability study are pending. Publishing review materials does not establish reviewer endorsement or completion.
