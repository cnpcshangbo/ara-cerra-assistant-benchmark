# Concepts

## Configured assistant
- **Notation**: —
- **Definition**: The model plus adapter, prompts, validation, internal repair, deterministic queries, answer rendering and browser effects.
- **Boundary conditions**: The unit measured here; not a foundation model evaluated in isolation.
- **Related concepts**: Strict success

## Strict success
- **Notation**: —
- **Definition**: A conjunctive pass requiring expected completion, selected-model identity, permitted operation/scope, source evidence, required narrative propositions and browser effects.
- **Boundary conditions**: Each missing essential requirement fails; optional qualifications are not promoted after observing outputs.
- **Related concepts**: Functional equivalence, UI-state violation

## UI-state violation
- **Notation**: —
- **Definition**: An observed value change that violates the frozen task policy.
- **Boundary conditions**: Redundant fields with unchanged values are excluded; requested changes can still be premature under clarify-first policy.
- **Related concepts**: Strict success

## Functional equivalence
- **Notation**: —
- **Definition**: A narrowly defined secondary diagnostic crediting practical correctness despite selected strict mismatches.
- **Boundary conditions**: Post-hoc in the initial campaign and inherited later; it never replaces the primary rubric.
- **Related concepts**: Strict success

## Independent oracle
- **Notation**: —
- **Definition**: Expected numeric, record, proposition, scope and state outcomes computed or fixed independently of the evaluated response and application answer path.
- **Boundary conditions**: Computational independence does not validate upstream extraction or provide independent data collection.
- **Related concepts**: Configured assistant

## Task-cluster bootstrap
- **Notation**: —
- **Definition**: Resampling task means while keeping all repeated attempts for each sampled task together.
- **Boundary conditions**: Percentile intervals depend on the convenience suite; they do not remove selection bias or establish population inference.
- **Related concepts**: Repeated-task consistency

## Repeated-task consistency
- **Notation**: —
- **Definition**: The directly observed count of primary tasks passing every recorded repetition.
- **Boundary conditions**: A descriptive count, not a separately estimated general reliability metric.
- **Related concepts**: Task-cluster bootstrap

## Identity-blind narrative review
- **Notation**: —
- **Definition**: A proposition review supplied frozen requirements and answers while withholding model identity and aggregate results.
- **Boundary conditions**: AI-assisted review is not human expert validation; missing backend metadata limits exact replay.
- **Related concepts**: Independent oracle

## Public derivative
- **Notation**: —
- **Definition**: A release that retains authorized scientific information with explicit record-field redactions and separately computed public hashes.
- **Boundary conditions**: Original archive hashes identify originals, not byte-identical public files; omitted raw evidence limits replay.
- **Related concepts**: Independent oracle
